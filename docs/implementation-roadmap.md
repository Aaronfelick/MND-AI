# Implementation roadmap

This roadmap turns the current launch kit into a real delivery business and, if you want, into a SaaS product later.

## Stage 1: Productized service foundation

Goal: sell and deliver the offer manually with high quality.

Build:

- one niche-specific landing page
- one intake form for client discovery
- one onboarding questionnaire
- one repeatable client profile JSON template
- one live demo chatbot on your own site

Focus:

- pick one vertical first, not all local businesses at once
- keep the first version service-heavy and software-light
- turn every delivery step into a checklist

## Stage 2: Delivery automation

Goal: reduce manual effort per client.

Add:

- a web form that writes directly into the business profile JSON format
- a dashboard that previews schema and chatbot assets without editing raw JSON
- a content checklist for missing trust signals, FAQs, and service gaps
- export buttons for JSON-LD, knowledge base, and prompt files

Nice-to-have integrations:

- Google Business Profile data import
- website crawler for extracting service pages and FAQs
- review summarization
- CRM lead export

## Stage 3: Production chatbot deployment

Goal: move from generated prompt files to a working client-facing assistant.

Implement:

1. chat widget UI
2. LLM backend with system prompt + retrieval context
3. knowledge-base storage
4. lead capture flow
5. analytics events
6. handoff to WhatsApp, phone, booking, or human support

Important guardrails:

- use only approved client content
- support human escalation
- log unanswered questions
- avoid unsupported claims in regulated categories

## Stage 4: AEO measurement and reporting

Goal: prove value beyond “we added schema.”

Track:

- organic visits to service and FAQ pages
- inquiries attributed to chat
- booking starts from the site
- click-throughs to WhatsApp or phone
- visibility for city + service + trust-intent queries
- whether AI assistants and AI overviews surface the business more clearly over time

Client reporting should stay simple:

- what changed
- what new questions are being captured
- what conversions the bot influenced
- what pages or entities still need better coverage

## Stage 5: Niche expansion

Goal: expand from one niche to several adjacent ones.

Example sequence:

1. tailors and alterations
2. salons and spas
3. dental and aesthetic clinics
4. gyms and personal training studios
5. home services

Why this order works:

- local service intent is strong
- repeated questions are common
- booking behavior is easy to understand
- the same asset-generation model still applies

## Stage 6: SaaS transition

Goal: turn the service engine into software clients or agencies can use directly.

Potential product features:

- multi-client dashboard
- template library by niche
- schema validation
- FAQ generation workflow with approvals
- chatbot testing simulator
- analytics and ROI reporting
- role-based access for agency teams

At this stage, MND-AI becomes less like an agency toolkit and more like:

- an AEO operations platform
- a website-conversion assistant builder
- or a hybrid agency-plus-software product

## Recommended order of execution

If you want the fastest path to real revenue, do this in order:

1. choose one vertical and one city cluster
2. create 3 strong sample profiles
3. put one demo on your own site
4. sell manual pilot projects
5. automate the intake and export steps
6. add a production-grade chat deployment
7. build reporting and recurring retainer offers
